Implement an enhanced storage adapter for the grammY library. You can read more about enhancing `StorageAdapter` from https://github.com/grammyjs/grammY/blob/main/src/convenience/session.ts#L479. As part of the plugin, implement an Interface that contains at least the methods `encrypt` and `decrypt` with a standardised type signature. This will allow us to accept any user-provided alternative encryption as long as they implement this interface. We will also implement a default version of this Interface if none is provided by the user. This enhanced storage adapter should encrypt before writing to storage, and decrypt before reading from storage.
